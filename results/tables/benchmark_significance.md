# Pairwise comparisons of test MAE

mae_diff = MAE(a) - MAE(b) on test predictions pooled over 5 seeds (negative: a better); the 95% CI and p_boot (fraction of 2000 paired bootstrap resamples with diff >= 0) resample compounds only, not splits. Wilcoxon signed-rank test on the 5 per-seed MAEs (exact): with n = 5 the smallest attainable p is 0.0625 two-sided / 0.031 one-sided, so it cannot reach p < 0.05 two-sided (very low power).
